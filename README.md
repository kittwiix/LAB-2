# Отделочные материалы — расчёт закупки

Консольное приложение для расчёта количества и стоимости отделочных материалов
при закупке по площади: обои, плитка, ламинат.

Лабораторная работа № 2 по дисциплине «Теория алгоритмов», вариант 10.

## Возможности

- расчёт обоев по площади рулона (53 см или 106 см на 10 м);
- расчёт плитки по площади плитки (20 x 20, 30 x 30 или 60 x 60 см);
- расчёт ламината по площади упаковки;
- учёт запаса на подрезку, по умолчанию 10 %;
- сохранение расчётов в базу данных sqlite3;
- экспорт расчётов в файлы report.docx и report.xlsx.


```bash
python -m pip install -r requirements.txt
python main.py
```


## Краткая справка

Количество к закупке: N = ceil(S * (1 + z / 100) / s), где S — площадь поверхности,
z — запас на подрезку в процентах, s — площадь рулона, плитки или упаковки.
Стоимость: C = N * p, где p — цена единицы материала.
